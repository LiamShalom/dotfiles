# Provider policy audits

Before classifying a policy breach as confirmed, match the clause's regulated actor and use case to the observed deployment. Separate a service handling other people's accounts from a private tool used only by the owner of its accounts. An explicit rule for the former is not automatically an explicit rule for the latter. Label an unresolved interpretation as uncertain, and retain the evidence that would resolve it.

For Liam's private local pool, preserving Max's included allowance is the core cost constraint (2026-10-29); present metered API billing as a different economic option, never an equivalent fix for that goal.
